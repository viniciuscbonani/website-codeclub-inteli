# CodeClub — protótipo de alta fidelidade

Landing page responsiva e fluxo de autenticação criados a partir do wireframe e das referências visuais do Figma.

## Visualizar

Abra `index.html` diretamente no navegador ou execute um servidor estático na pasta:

```bash
python3 -m http.server 4173
```

Depois acesse `http://localhost:4173`.

## Estrutura

- `index.html`: landing page, carrossel de eventos e narrativa interativa no scroll.
- `login.html`: tela de entrada.
- `signup.html`: tela de cadastro.
- `styles.css`: sistema visual, responsividade e animações.
- `app.js`: carrosséis, narrativa sticky, menu móvel, FAQ, autenticação demonstrativa e microinterações.
- `public/assets/references`: imagens originais extraídas do frame de referência no Figma.
- `public/assets/events`: imagens provisórias do carrossel de eventos, geradas para o protótipo.

Os formulários são demonstrativos e não enviam dados.
